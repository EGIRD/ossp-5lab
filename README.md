# Лабораторная работа №5. Элементы сетевого программирования (Вариант 10)

## Назначение приложения
Удаленный интерпретатор операций с файлами (TCP) на базе Windows Sockets API, ограничивающий доступ к файловой системе выделенным каталогом `sandbox`.

## Требования к окружению
- ОС Windows 10/11
- Компилятор C++17 (MinGW `g++`) с библиотекой `ws2_32`
- Python 3.8+ (`pandas`, `matplotlib`) для построения графиков

## Команды сборки
```cmd
g++ -std=c++17 -O2 -Wall src/server/server.cpp -o server.exe -lws2_32
g++ -std=c++17 -O2 -Wall src/client/client.cpp -o client.exe -lws2_32
